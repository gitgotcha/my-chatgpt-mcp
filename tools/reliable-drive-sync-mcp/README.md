# Reliable Drive Sync MCP

This is the local WorkBuddy stdio entry point for Reliable Drive Sync. It
exposes exactly one MCP tool: `submit_event`, and forwards validated JSON-RPC
calls to the configured Worker ingress.

The launcher reads these environment variables without printing them:

- `RELIABLE_DRIVE_SYNC_NODE_PATH` (optional; defaults to `node`)
- `RELIABLE_DRIVE_SYNC_INGRESS_URL`
- `RELIABLE_DRIVE_SYNC_INGRESS_SHARED_SECRET`

WorkBuddy should point to `start.cmd` from a stable checkout. Do not point it at
the historical WorkBuddy package build, and do not place a secret in a committed
configuration file.

After restarting WorkBuddy, `tools/list` must return only:

```text
["submit_event"]
```

## ChatGPT Work developer-mode connection

The recommended personal setup is now the Worker's capability URL generated by
`services/reliable-drive-sync-worker/setup-chatgpt-work.ps1`. It does not need a
local process or Secure MCP Tunnel. Use the tunnel instructions below only when
the target OpenAI account actually exposes Tunnels and the Worker must remain
private.

ChatGPT Work does not read Codex `config.toml` or a local `stdio` command. For
private development, use OpenAI Secure MCP Tunnel. It keeps the Worker secret
and the stdio bridge on the Windows machine; only the tunnel endpoint is
selected in ChatGPT.

Prerequisites:

- Developer mode enabled in ChatGPT Work.
- A tunnel created and associated with the target ChatGPT workspace in OpenAI
  Platform.
- The latest `tunnel-client` executable and a runtime API key.
- The two `RELIABLE_DRIVE_SYNC_*` user environment variables configured as
  described above.

From PowerShell, set the runtime key only for the current process and run the
helper from this checkout:

```powershell
$env:CONTROL_PLANE_API_KEY = 'sk-...'
& .\setup-chatgpt-work-tunnel.ps1 `
  -TunnelId 'tunnel_...' `
  -TunnelClientPath 'C:\path\to\tunnel-client.exe'
```

The helper runs `init` and `doctor`, then prints the command that must remain
running:

```powershell
& 'C:\path\to\tunnel-client.exe' run --profile reliable-drive-sync
```

In ChatGPT Work: Settings → Security and login → enable Developer mode, open
Plugins, choose `+`, select **Tunnel**, select the associated tunnel, and create
the developer app. Start a new conversation, add the app, and verify that the
only discovered tool is `submit_event`.

For a command-only check that does not need the runtime key:

```powershell
& .\setup-chatgpt-work-tunnel.ps1 -TunnelId 'tunnel_...' -DryRun
```

Secure MCP Tunnel is for private/developer-mode use and is not a substitute for
the stable public `/mcp` endpoint and OAuth required for plugin distribution.
